# Translations

Korean translations of Japanese concert playlists. Each folder contains per-song Markdown files with original Japanese lyrics, Korean phonetic reading, and Korean meaning translation.

**어디서부터 들을지 모르겠다면** → [라이브 통계](LIVE_STATS.md): 아티스트별로 라이브에서 많이 부르는 곡 TOP 3. 각 `- ALL` 폴더 README 맨 위에는 최근 공연 셋리스트와 라이브 단골곡 순위가 있다.
