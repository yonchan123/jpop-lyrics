# TRY AGAIN

**水樹奈々**

---

**作词 : 矢吹俊郎**  
작곡 : 矢吹俊郎

**時々現れる　眩しい光に　倒れそうな瞳　負けたくはないから**  
토키도키 아라와레루 마부시이 히카리니 타오레소오나 히토미 마케타쿠와 나이카라  
때때로 나타나는 눈부신 빛에 쓰러질 듯한 눈동자, 지고 싶지 않으니까

**大人の世界では　当たり前の事　遠回りの　意味を掴まなくちゃ**  
오토나노 세카이데와 아타리마에노 코토 토오마와리노 이미오 츠카마나쿠챠  
어른의 세계에서는 당연한 일, 돌아가는 길의 의미를 붙잡아야 해

**悲しまないで、ほら　揺れる未来を**  
카나시마나이데, 호라 유레루 미라이오  
슬퍼하지 마, 봐, 흔들리는 미래를

**はじめから　思い出して**  
하지메카라 오모이다시테  
처음부터 떠올려봐

**誰でも　うれしくて　はしゃぎだすような**  
다레데모 우레시쿠테 하샤기다스요오나  
누구든 기뻐서 들떠 날뛰는 듯한

**華々しい瞬間に　また出会える日が来るよ**  
하나바나시이 슌칸니 마타 데아에루 히가 쿠루요  
화려한 순간에 다시 만날 날이 와

**もう一度　スランプを　抜け出すためには**  
모오 이치도 스란푸오 누케다스 타메니와  
다시 한 번 슬럼프를 빠져나가기 위해서는

**やりたい事を　今すぐ！**  
야리타이 코토오 이마스구!  
하고 싶은 일을 지금 당장!

**考え過ぎずに　自分を開いて**  
칸가에스기즈니 지분오 히라이테  
너무 생각하지 말고 자신을 열어

**今時の社会じゃ　認められないと　守られてく道も　閉ざされて行くけど**  
이마도키노 샤카이쟈 미토메라레나이토 마모라레테쿠 미치모 토자사레테 유쿠케도  
요즘 사회에선 인정받지 못하면 지켜지던 길도 닫혀 가지만

**描き出した未来　想像してみよう　早送りで　夢を求めないで**  
에가키다시타 미라이 소오조오시테 미요오 하야오쿠리데 유메오 모토메나이데  
그려낸 미래를 상상해 보자, 빨리감기로 꿈을 좇지 마

**やすらぎのひと時　味わいながら**  
야스라기노 히토토키 아지와이나가라  
편안한 한때를 맛보면서

**ゆっくりで　いいはずなの**  
윳쿠리데 이이 하즈나노  
천천히 해도 괜찮을 거야

**ときめき　忘れずに　穏やかに進む**  
토키메키 와스레즈니 오다야카니 스스무  
설렘을 잊지 말고 차분히 나아가

**相変わらず毎日は　気軽にはいかないけど**  
아이카와라즈 마이니치와 키가루니와 이카나이케도  
변함없이 매일은 가볍게 흘러가진 않지만

**試しに　努力でも　してみたらイイね**  
타메시니 도료쿠데모 시테미타라 이이네  
시험삼아 노력이라도 해보면 좋겠어

**やれない事は　飛ばして！**  
야레나이 코토와 토바시테!  
못 하는 건 건너뛰고!

**ひとつひとつなら　クリアーできそう**  
히토츠 히토츠나라 쿠리아아 데키소오  
하나하나라면 클리어할 수 있을 것 같아

**自分で　決めたから　やりかけた事を**  
지분데 키메타카라 야리카케타 코토오  
스스로 정했으니까 하다 만 일을

**今更投げ出せないし　やるだけやってみようじゃない**  
이마사라 나게다세나이시 야루다케 얏테 미요오쟈 나이  
이제 와서 내던질 수 없고 할 만큼 해보자

**今度は　寂しさも　吹き飛ばすような**  
콘도와 사미시사모 후키토바스요오나  
이번엔 쓸쓸함도 날려버릴 듯한

**晴々しい感覚に　また出会える日が来るよ**  
하레바레시이 칸카쿠니 마타 데아에루 히가 쿠루요  
상쾌한 감각에 다시 만날 날이 와

**もう一度　スランプを　抜け出すためには**  
모오 이치도 스란푸오 누케다스 타메니와  
다시 한 번 슬럼프를 빠져나가기 위해서는

**やりたい事を　今すぐ！**  
야리타이 코토오 이마스구!  
하고 싶은 일을 지금 당장!

**考え過ぎずに　自分を開いて**  
칸가에스기즈니 지분오 히라이테  
너무 생각하지 말고 자신을 열어
