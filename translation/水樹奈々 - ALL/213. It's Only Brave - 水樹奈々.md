# It's Only Brave

**水樹奈々**

---

**作词 : オオヤギヒロオ**  
작곡 : オオヤギヒロオ

**あの日君が心に抱(いだ)いた　想いがまだ残ってるなら**  
아노 히 키미가 코코로니 이다이타 오모이가 마다 노콧테루나라  
그날 네가 마음에 품었던 생각이 아직 남아 있다면

**それはきっと憧れじゃなくて　自分自身との約束なんだよ**  
소레와 킷토 아코가레쟈 나쿠테 지분 지신토노 야쿠소쿠난다요  
그건 분명 동경이 아니라 자기 자신과의 약속이야

**誰かの背中眺めたら　胸の奥が痛くなる**  
다레카노 세나카 나가메타라 무네노 오쿠가 이타쿠 나루  
누군가의 등을 바라보면 가슴 깊은 곳이 아파와

**だけど全てを受け止めれば　きっと強くなれるから**  
다케도 스베테오 우케토메레바 킷토 츠요쿠 나레루카라  
하지만 모든 걸 받아들이면 분명 강해질 수 있으니까

**叶えたい未来にTry　果てしのない道のり**  
카나에타이 미라이니 Try 하테시노 나이 미치노리  
이루고 싶은 미래에 Try 끝없는 여정

**ためらわず行けばいい**  
타메라와즈 이케바 이이  
망설임 없이 가면 돼

**It's only brave　明日のキセキを信じて**  
It's only brave 아시타노 키세키오 신지테  
It's only brave 내일의 기적을 믿으며

**大切な夢に向かい　ただ今を駆け抜けよう**  
타이세츠나 유메니 무카이 타다 이마오 카케누케요우  
소중한 꿈을 향해 그저 지금을 달려나가자

**手を触れたらすぐに離れてく　形のないものだけれど**  
테오 후레타라 스구니 하나레테쿠 카타치노 나이 모노다케레도  
손을 대면 곧 멀어져 가는 형체 없는 것이지만

**積み重ねた毎日の先に　探していた答えがあるよ**  
츠미카사네타 마이니치노 사키니 사가시테이타 코타에가 아루요  
쌓아온 매일의 끝에 찾고 있던 답이 있어

**涙こらえてみつけよう　遠くに続く足跡**  
나미다 코라에테 미츠케요우 토오쿠니 츠즈쿠 아시아토  
눈물을 참으며 찾아내자 멀리 이어지는 발자국

**一人じゃないと気付けたなら　もっと強くなれるから**  
히토리쟈 나이토 키즈케타나라 못토 츠요쿠 나레루카라  
혼자가 아니라고 깨달으면 더 강해질 수 있으니까

**こたえたい期待にTry　止められない情熱**  
코타에타이 키타이니 Try 토메라레나이 죠우네츠  
부응하고 싶은 기대에 Try 멈출 수 없는 정열

**青空に解き放とう**  
아오조라니 토키하나토우  
푸른 하늘에 풀어놓자

**It's only brave　ゆずれない願いを信じて**  
It's only brave 유즈레나이 네가이오 신지테  
It's only brave 양보할 수 없는 소원을 믿으며

**二度とないこの季節を　迷わずに駆け抜けよう**  
니도토 나이 코노 키세츠오 마요와즈니 카케누케요우  
두 번 다시 없는 이 계절을 망설임 없이 달려나가자
