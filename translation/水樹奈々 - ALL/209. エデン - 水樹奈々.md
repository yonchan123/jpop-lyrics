# エデン

**水樹奈々**

---

**作词 : 水樹奈々**  
작곡 : 藤森真一

**それは、溶けてしまいそうな　淡い二人の囁き**  
소레와, 토케테시마이소오나 아와이 후타리노 사사야키  
그것은, 녹아버릴 것 같은 아련한 두 사람의 속삭임

**照らして、照らして…青い花**  
테라시테, 테라시테…아오이 하나  
비춰줘, 비춰줘…푸른 꽃

**長い沈黙掻き消すような**  
나가이 친모쿠 카키케스요오나  
긴 침묵을 지워버릴 듯한

**光の粒が髪を伝うよ**  
히카리노 츠부가 카미오 츠타우요  
빛의 알갱이가 머리카락을 타고 흘러

**どんな言葉も陳腐に見えて**  
돈나 코토바모 친푸니 미에테  
어떤 말도 진부해 보여서

**重なる指に答え求めた**  
카사나루 유비니 코타에 모토메타  
포개진 손가락에 답을 구했어

**もう少し傍にいて**  
모오 스코시 소바니 이테  
조금만 더 곁에 있어줘

**時間よ止まって…**  
지칸요 토맛테…  
시간이여 멈춰줘…

**愛する意味も知らずに**  
아이스루 이미모 시라즈니  
사랑하는 의미도 모른 채

**愛されたいと願った**  
아이사레타이토 네갓타  
사랑받고 싶다고 바랐어

**勝手な想いが先走る**  
캇테나 오모이가 사키바시루  
제멋대로인 마음이 앞서가

**やがて大人になって**  
야가테 오토나니 낫테  
이윽고 어른이 되어

**可笑しいと笑うだろうか**  
오카시이토 와라우다로오카  
우습다고 웃을까

**教えて、教えて　青い花**  
오시에테, 오시에테 아오이 하나  
알려줘, 알려줘 푸른 꽃

**息で曇った窓に描いた**  
이키데 쿠못타 마도니 에가이타  
입김으로 흐려진 창에 그렸어

**二人の夢が切なく浮かぶ**  
후타리노 유메가 세츠나쿠 우카부  
두 사람의 꿈이 애달프게 떠올라

**あの日まで戻れるなら**  
아노 히마데 모도레루나라  
그날까지 돌아갈 수 있다면

**何かが変わった…？**  
나니카가 카왓타…?  
무언가 변했을까…?

**声にならない気持ちが**  
코에니 나라나이 키모치가  
목소리가 되지 못한 마음이

**心の自由奪って**  
코코로노 지유우 우밧테  
마음의 자유를 빼앗아

**悲しい記憶を繰り返す**  
카나시이 키오쿠오 쿠리카에스  
슬픈 기억을 반복해

**やがて大人になって**  
야가테 오토나니 낫테  
이윽고 어른이 되어

**忘れてしまうだろうか**  
와스레테시마우다로오카  
잊어버릴까

**小さな、小さな　青い花**  
치이사나, 치이사나 아오이 하나  
작은, 작은 푸른 꽃

**我が儘で　眩しくて**  
와가마마데 마부시쿠테  
제멋대로이고 눈부셔서

**幸せは望むほど遠くに感じるけど**  
시아와세와 노조무 호도 토오쿠니 칸지루케도  
행복은 바랄수록 멀게 느껴지지만

**二人だけの明日があると信じている**  
후타리다케노 아시타가 아루토 신지테이루  
둘만의 내일이 있다고 믿고 있어

**だから…**  
다카라…  
그러니까…

**愛する意味も知らずに**  
아이스루 이미모 시라즈니  
사랑하는 의미도 모른 채

**愛されたいと願った**  
아이사레타이토 네갓타  
사랑받고 싶다고 바랐어

**勝手な想いが先走る**  
캇테나 오모이가 사키바시루  
제멋대로인 마음이 앞서가

**やがて大人になって**  
야가테 오토나니 낫테  
이윽고 어른이 되어

**可笑しいと笑うだろうか**  
오카시이토 와라우다로오카  
우습다고 웃을까

**教えて、教えて　青い花**  
오시에테, 오시에테 아오이 하나  
알려줘, 알려줘 푸른 꽃
