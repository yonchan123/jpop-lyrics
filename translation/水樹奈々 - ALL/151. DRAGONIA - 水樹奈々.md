# DRAGONIA

**水樹奈々**

---

**作词 : Hibiki**  
작곡 : 俊龍

**「生命(いのち)さえ 賭けてもいい」 青天に飛べ**  
"이노치사에 카케테모 이이" 세이텐니 토베  
"생명조차 걸어도 좋아" 푸른 하늘로 날아라

**その重きを知るのならば 焼ける夕陽の様な**  
소노 오모키오 시루노나라바 야케루 유우히노 요오나  
그 무거움을 안다면 타오르는 석양 같은

**輝きになれるよ**  
카가야키니 나레루요  
빛이 될 수 있어

**吹き荒れる疾風(はやて)よ 酷く暴れようが**  
후키아레루 하야테요 히도쿠 아바레요오가  
몰아치는 질풍이여 거세게 날뛰어도

**万里渡って来た 炎消せるか？**  
반리 와탓테 키타 호노오 케세루카?  
만리를 건너온 불꽃을 끌 수 있을까?

**古(いにしえ)に焦がれて どうして生まれよう？**  
이니시에니 코가레테 도오시테 우마레요오?  
옛것을 그리워하며 어찌 태어날까?

**今この胸 叩く鼓動 これが時代さ**  
이마 코노 무네 타타쿠 코도오 코레가 지다이사  
지금 이 가슴을 두드리는 고동 이것이 시대야

**龍が昇る光の如く… 逆鱗が煌めく…**  
류우가 노보루 히카리노 고토쿠… 게키린가 키라메쿠…  
용이 솟아오르는 빛처럼… 역린이 빛나…

**触れずして夢と言えようか？**  
후레즈시테 유메토 이에요오카?  
닿지도 않고 꿈이라 할 수 있을까?

**「生命(いのち)さえ 賭けてもいい」 青天に飛べ**  
"이노치사에 카케테모 이이" 세이텐니 토베  
"생명조차 걸어도 좋아" 푸른 하늘로 날아라

**道無き道選んだ 間違いじゃなかった**  
미치 나키 미치 에란다 마치가이쟈나캇타  
길 없는 길을 택했어 잘못이 아니었어

**ZEROになる 勇気こそ 進化のTrue blade**  
ZERO니 나루 유우키코소 신카노 True blade  
ZERO가 되는 용기야말로 진화의 True blade

**独立せよ過去の日から**  
도쿠리츠세요 카코노 히카라  
독립하라 과거의 날들로부터

**恐れる事はない 僕と共にゆこう**  
오소레루 코토와 나이 보쿠토 토모니 유코오  
두려워할 것 없어 나와 함께 가자

**人は何時の日にか 過ちが蝕(むしば)み**  
히토와 이츠노 히니카 아야마치가 무시바미  
사람은 언젠가 잘못이 좀먹어

**喉を枯らし泣くと 何故わからない？**  
노도오 카라시 나쿠토 나제 와카라나이?  
목이 쉬도록 운다는 걸 왜 모르는 거야?

**護る人のために 愛は翳(かざ)すものと**  
마모루 히토노 타메니 아이와 카자스 모노토  
지킬 사람을 위해 사랑은 드리우는 것이라고

**揺るぐ事ない 心こそが 己(おの)が武であれ**  
유루구 코토 나이 코코로코소가 오노가 부데 아레  
흔들리지 않는 마음이야말로 자신의 무기일지니

**一つ二つ歩んだ足よ… 傷だらけの両手よ…**  
히토츠 후타츠 아윤다 아시요… 키즈다라케노 료오테요…  
하나 둘 걸어온 발이여… 상처투성이의 두 손이여…

**歴史を名乗ろう涙の数**  
레키시오 나노로오 나미다노 카즈  
역사를 자처하자 눈물의 수만큼

**突き上げた 熱情は 言葉を超えて**  
츠키아게타 네츠죠오와 코토바오 코에테  
치밀어 오른 열정은 말을 넘어서

**始まりだと知るんだ 不死なる真の決意**  
하지마리다토 시룬다 후시나루 신노 케츠이  
시작이라는 걸 알아 불사의 진정한 결의

**空となれ 旅人よ 風に幸あれ**  
소라토 나레 타비비토요 카제니 사치 아레  
하늘이 되어라 나그네여 바람에 행복 있으라

**感じたのならば儚き ディストピアを去りて**  
칸지타노나라바 하카나키 디스토피아오 사리테  
느꼈다면 덧없는 디스토피아를 떠나서

**明日へとゆこうか**  
아시타에토 유코오카  
내일로 가볼까

**優しさ纏(まと)いしは 「力」などと惑わず**  
야사시사 마토이시와 "치카라" 나도토 마도와즈  
다정함을 두른 것을 "힘" 따위로 헷갈리지 말고

**熱き想い 熱き願い 踏み出そうか？**  
아츠키 오모이 아츠키 네가이 후미다소오카?  
뜨거운 마음 뜨거운 소원 내디뎌 볼까?

**僕と今…**  
보쿠토 이마…  
나와 함께 지금…

**嘆き憂い戦(おのの)き怯え すべて出し尽くして**  
나게키 우레이 오노노키 오비에 스베테 다시츠쿠시테  
탄식하고 근심하고 떨고 겁먹어 모든 것을 쏟아내고

**それでもハート打つのは何故？**  
소레데모 하아토 우츠노와 나제?  
그래도 하트가 뛰는 건 어째서?

**「生命(いのち)さえ 賭けてもいい」 青天に飛べ**  
"이노치사에 카케테모 이이" 세이텐니 토베  
"생명조차 걸어도 좋아" 푸른 하늘로 날아라

**ZEROになれ 勇気こそ 進化のTrue blade**  
ZERO니 나레 유우키코소 신카노 True blade  
ZERO가 되어라 용기야말로 진화의 True blade

**「我思う、故に我在り」 共鳴せよ運命(さだめ)**  
"와레 오모우, 유에니 와레 아리" 쿄오메이세요 사다메  
"나는 생각한다, 고로 존재한다" 공명하라 운명이여

**僕なら側にいる**  
보쿠나라 소바니 이루  
나라면 곁에 있어
