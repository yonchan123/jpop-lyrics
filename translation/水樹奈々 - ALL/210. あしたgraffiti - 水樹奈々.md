# あしたgraffiti

**水樹奈々**

---

**作词 : 藤林聖子**  
작곡 : 加藤裕介

**改札を抜けて　スイッチ“OFFICIAL”入れて**  
카이사츠오 누케테 스잇치 "OFFICIAL" 이레테  
개찰구를 빠져나와 스위치 "OFFICIAL"을 켜고

**髪をなびかせて　忙しい街へと踏み出すけど**  
카미오 나비카세테 이소가시이 마치에토 후미다스케도  
머리카락을 휘날리며 분주한 거리로 발을 내딛지만

**ドキッとする着信　瞬間うろたえちゃう**  
도킷토스루 챠쿠신 슌칸 우로타에챠우  
철렁하게 만드는 착신, 순간 허둥대고 말아

**ヤバってなる　ハイヒール**  
야밧테나루 하이히이루  
큰일 났다 싶은 하이힐

**ふらつくメンタル鍛え直そう**  
후라츠쿠 멘타루 키타에나오소우  
흔들리는 멘탈을 다시 단련하자

**なりたい私にまだ　遠いけどトライone more time**  
나리타이 와타시니 마다 토오이케도 토라이 one more time  
되고 싶은 나에겐 아직 멀지만 도전 one more time

**目標だけは　高めキープで**  
모쿠효우다케와 타카메 키이푸데  
목표만큼은 높게 유지하며

**まだまだ行ける！**  
마다마다 이케루!  
아직 더 갈 수 있어!

**さぁ心に**  
사아 코코로니  
자 마음에

**あしたgraffiti　自由に**  
아시타 graffiti 지유우니  
내일의 graffiti 자유롭게

**果てしない夢と　野望を**  
하테시나이 유메토 야보우오  
끝없는 꿈과 야망을

**描き続けよう**  
에가키츠즈케요우  
계속 그려가자

**カラフル！あしたgraffiti　いつでも**  
카라후루! 아시타 graffiti 이츠데모  
컬러풀! 내일의 graffiti 언제나

**今日より輝きを放つ**  
쿄우요리 카가야키오 하나츠  
오늘보다 빛을 발하는

**私に出逢えるはずと**  
와타시니 데아에루 하즈토  
나와 만날 수 있을 거라고

**信じて歩いて行こうよずっと**  
신지테 아루이테 이코우요 즛토  
믿으며 계속 걸어가자

**オトナ目のワードローブ　控えめネイル　丁寧語**  
오토나메노 와아도로오부 히카에메 네이루 테이네이고  
어른스러운 워드로브 절제된 네일 존댓말

**ごめん君のこと　すっかり後回しにしちゃった!!**  
고멘 키미노 코토 슷카리 아토마와시니 시챳타!!  
미안 너에 대한 일 완전히 뒷전으로 미뤄버렸어!!

**何かにのめり込むと　切り替え出来ない、ほんと**  
나니카니 노메리코무토 키리카에 데키나이, 혼토  
무언가에 빠져들면 전환을 못 해, 정말로

**多機能なハート　搭載できたら　素敵なのにね**  
타키노우나 하아토 토우사이 데키타라 스테키나노니네  
다기능 하트를 탑재할 수 있다면 멋질 텐데

**さぁ今すぐ**  
사아 이마스구  
자 지금 당장

**あしたgraffiti　はみ出そう**  
아시타 graffiti 하미다소우  
내일의 graffiti 삐져나가자

**周り見比べて　小さく**  
마와리 미쿠라베테 치이사쿠  
주위와 비교하며 작게

**纏めなくていい**  
마토메나쿠테 이이  
정리하지 않아도 돼

**ポップに　あしたgraffiti　そのまま**  
폿푸니 아시타 graffiti 소노마마  
팝하게 내일의 graffiti 그대로

**リミットかけない理想を**  
리밋토 카케나이 리소우오  
한계를 두지 않는 이상을

**好きな色で染上げて**  
스키나 이로데 소메아게테  
좋아하는 색으로 물들여

**未来の私に見せてあげよう**  
미라이노 와타시니 미세테 아게요우  
미래의 나에게 보여주자
