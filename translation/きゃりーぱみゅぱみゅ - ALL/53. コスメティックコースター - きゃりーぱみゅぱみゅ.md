# コスメティックコースター

**きゃりーぱみゅぱみゅ**

---

**作词 : 中田ヤスタカ**  
작곡 : 中田ヤスタカ

**ようこそみんなで造る 夢のコースター**  
요오코소 민나데 츠쿠루 유메노 코오스타아  
어서 와, 다 같이 만드는 꿈의 코스터

**あたしの描くちょっぴりイジワルな**  
아타시노 에가쿠 춋피리 이지와루나  
내가 그리는 살짝 짓궂은

**そう 魔法を かけてあげるから 最後までよろしくね**  
소오 마호오오 카케테 아게루카라 사이고마데 요로시쿠네  
그래, 마법을 걸어 줄 테니까 끝까지 잘 부탁해

**コスメティック キミに 憧れて**  
코스메팃쿠 키미니 아코가레테  
코스메틱 너를 동경해서

**夢のオーケストラ コスメティック コースター**  
유메노 오오케스토라 코스메팃쿠 코오스타아  
꿈의 오케스트라 코스메틱 코스터

**ちょうだいよパラダイス カケラだけ**  
쵸오다이요 파라다이스 카케라다케  
줘 파라다이스 조각만이라도

**持ち帰る 思い出を コンパクトに閉じこめて**  
모치카에루 오모이데오 콘파쿠토니 토지코메테  
가져갈 추억을 콤팩트에 가둬 두고

**みんなでドッキリすれば こわくないわ**  
민나데 돗키리 스레바 코와쿠나이와  
다 같이 깜짝 놀라면 무섭지 않아

**秘密の呪文を今ね 唱えよう**  
히미츠노 쥬몬오 이마네 토나에요오  
비밀 주문을 지금 외워 보자

**新しいドアを叩くなら**  
아타라시이 도아오 타타쿠나라  
새로운 문을 두드릴 거라면

**丁寧よりも壊したい**  
테이네이요리모 코와시타이  
얌전히 열기보다 부숴 버리고 싶어

**コスメティック キミに 憧れて**  
코스메팃쿠 키미니 아코가레테  
코스메틱 너를 동경해서

**夢のオーケストラ コスメティック コースター**
