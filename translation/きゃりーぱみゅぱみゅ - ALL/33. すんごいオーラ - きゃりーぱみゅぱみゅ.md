# すんごいオーラ

**きゃりーぱみゅぱみゅ**

---

**作词 : 中田ヤスタカ**  
작곡 : 中田ヤスタカ

**ちょうどの温度の日曜日**  
쵸오도노 온도노 니치요오비  
딱 알맞은 온도의 일요일

**ぬるめでさっぱり浴びるシャワー**  
누루메데 삿파리 아비루 샤와아  
미지근하게 개운하게 하는 샤워

**服をゆっくり選ぶけど**  
후쿠오 윳쿠리 에라부케도  
옷을 천천히 고르지만

**欲しいの欲しいの新しいの**  
호시이노 호시이노 아타라시이노  
갖고 싶어 갖고 싶어 새 거

**ちょうどの感じを超えたくて**  
쵸오도노 칸지오 코에타쿠테  
딱 적당한 느낌을 넘고 싶어서

**色々やってみたりもして**  
이로이로 얏테 미타리모 시테  
이것저것 해 보기도 하고

**かわいくなれたらいいな**  
카와이쿠 나레타라 이이나  
귀여워질 수 있으면 좋겠다

**すごいすごいってなるくらい**  
스고이 스고잇테 나루 쿠라이  
대단해 대단해 할 만큼

**どうすれば プラス的な**  
도오스레바 푸라스테키나  
어떻게 하면 긍정적인

**思い入れが 磨けるのかな**  
오모이이레가 미가케루노카나  
애정을 갈고닦을 수 있을까

**描くなら イマジネイション**  
에가쿠나라 이마지네이숀  
그린다면 이매지네이션

**つめ込むステキに囲まれて**  
츠메코무 스테키니 카코마레테  
가득 채운 멋진 것들에 둘러싸여

**散歩のコースに猫がいて**  
산포노 코오스니 네코가 이테  
산책길에 고양이가 있어서

**微妙な距離を歩いてる**  
비묘오나 쿄리오 아루이테루  
미묘한 거리를 두고 걷고 있어

**こっちに来いと誘うけど**  
콧치니 코이토 사소우케도  
이리 오라고 불러 보지만

**ておーい ておーいって逃げてくよ**  
테오오이 테오오잇테 니게테쿠요  
어이 어이 하는 사이에 도망가 버려

**いつもの感じのままよりも**  
이츠모노 칸지노 마마요리모  
평소 같은 느낌 그대로보다는

**チャレンジ大事なお年頃**  
챠렌지 다이지나 오토시고로  
도전이 중요한 나이

**かわいくなれたらいいな**  
카와이쿠 나레타라 이이나  
귀여워질 수 있으면 좋겠다

**すごいすごいってなるくらい**  
스고이 스고잇테 나루 쿠라이  
대단해 대단해 할 만큼

**すんごいオーラに包まれた**  
슨고이 오오라니 츠츠마레타  
엄청난 오라에 휩싸인

**まぶしいくらいの女の子**  
마부시이 쿠라이노 온나노코  
눈부실 만큼의 여자아이
