# 踊る子供、走るパトカー

**ネクライトーキー**

---

**作词 : もっさ**  
작곡 : もっさ

**天井は平行に**  
텐죠오와 헤이코오니  
천장은 평행하게

**消えた電気は無意識に冷えた窓から**  
키에타 덴키와 무이시키니 히에타 마도카라  
꺼진 전등은 무의식적으로 차가워진 창에서

**得体の知れぬ空気**  
에타이노 시레누 쿠우키  
정체 모를 공기

**おもちゃの拳銃に**  
오모챠노 켄쥬우니  
장난감 권총에

**弾を詰めては夜を更し遠くの街で走るパトカー**  
타마오 츠메테와 요오 후카시 토오쿠노 마치데 하시루 파토카아  
탄을 채우고는 밤을 지새우고 먼 거리에서 달리는 순찰차

**踊る　僕らのパーティーナイト**  
오도루 보쿠라노 파아티이 나이토  
춤추는 우리의 파티 나이트

**振り回したナイフでチキンを　切り分けてあげるよ**  
후리마와시타 나이후데 치킨오 키리와케테 아게루요  
휘두른 나이프로 치킨을 잘라 나눠줄게

**引き裂いて　剥いで**  
히키사이테 하이데  
찢어발기고 벗겨내고

**齧り付いて　食いちぎって笑う！**  
카지리츠이테 쿠이치깃테 와라우!  
물어뜯고 뜯어먹으며 웃는다!

**人形は悪役に**  
닌교오와 아쿠야쿠니  
인형은 악역으로

**締めたロープは無意識に食べたお菓子の**  
시메타 로오푸와 무이시키니 타베타 오카시노  
조인 밧줄은 무의식적으로 먹은 과자의

**空の袋がバラバラ**  
카라노 후쿠로가 바라바라  
빈 봉지가 뿔뿔이

**パトカーは唸る**  
파토카아와 우나루  
순찰차는 으르렁대

**食い逃げ犯を追いかけて家の窓から**  
쿠이니게한오 오이카케테 이에노 마도카라  
먹튀범을 쫓아서 집 창문에서

**愉快に見てる**  
유카이니 미테루  
유쾌하게 보고 있어

**大丈夫おもちゃだから**  
다이죠오부 오모챠다카라  
괜찮아 장난감이니까

왜냐면 이건 놀이니까

이츠카  
언젠가

**大人と呼ばれる事になれば…**  
오토나토 요바레루 코토니 나레바…  
어른이라 불리게 된다면…

**あれ僕ら今何者だろう**  
아레 보쿠라 이마 나니모노다로오  
어라 우린 지금 무엇일까

**怖いものなどないさ**  
코와이 모노나도 나이사  
무서운 건 따위 없어

**血だらけのナイフを握って何のために使うか**  
치다라케노 나이후오 니깃테 난노 타메니 츠카우카  
피투성이 나이프를 쥐고 무엇을 위해 쓸지

키카레탓테 사와이닷테 시라나이데  
물어봐도 떠들어도 모른 채로
