# 放課後の記憶

**ネクライトーキー**

---

**作词 : 朝日**  
작곡 : 朝日

**なんかわかりかねる**  
난카 와카리카네루  
어쩐지 잘 모르겠어

**秋も続く**  
아키모 츠즈쿠  
가을도 이어져

**子どもの僕らが**  
코도모노 보쿠라가  
어린 우리가

**何も言わずに見ていた**  
나니모 이와즈니 미테이타  
아무 말 없이 바라보고 있었어

**隣が終わらせて帰っていったら**  
토나리가 오와라세테 카엣테 잇타라  
옆 사람이 마치고 돌아가 버리면

**僕は一人ただ残り物を片付けてる**  
보쿠와 히토리 타다 노코리모노오 카타즈케테루  
나는 혼자 그저 남은 것들을 정리하고 있어

**誰かが大声で笑って通れば**  
다레카가 오오고에데 와랏테 토오레바  
누군가 큰 소리로 웃으며 지나가면

**肩身が狭くて壁に唾を吐く**  
카타미가 세마쿠테 카베니 츠바오 하쿠  
주눅이 들어 벽에 침을 뱉어

**すんでのとこまで来て**  
슨데노 토코마데 키테  
하마터면 하는 데까지 와서

**ちょっとは裏も見てて**  
춋토와 우라모 미테테  
조금은 이면도 보고서

**仰々しいほど陳腐な**  
교오교오시이 호도 친푸나  
거창할 만큼 진부한

**歌を好きになる**  
우타오 스키니 나루  
노래를 좋아하게 돼

**なんかわかりかねる**  
난카 와카리카네루  
어쩐지 잘 모르겠어

**猫も踊る**  
네코모 오도루  
고양이도 춤춰

**大人になれたら**  
오토나니 나레타라  
어른이 되면

**お金を何に使うの？**  
오카네오 나니니 츠카우노?  
돈을 뭐에 쓰는 거야?

**ちょっとわかりかねる**  
춋토 와카리카네루  
조금 잘 모르겠어

**秋も暮れる**  
아키모 쿠레루  
가을도 저물어

**窓を開けたら外から響く**  
마도오 아케타라 소토카라 히비쿠  
창문을 열면 밖에서 울려 퍼지는

**子どもが何回も**  
코도모가 난카이모  
아이가 몇 번이고

**笑う声を聞いてた**  
와라우 코에오 키이테타  
웃는 소리를 듣고 있었어

**辺りが暗くなる時間になれど**  
아타리가 쿠라쿠 나루 지칸니 나레도  
주변이 어두워지는 시간이 되어도

**明かりも点けずに部屋で一人待つ**  
아카리모 츠케즈니 헤야데 히토리 마츠  
불도 켜지 않고 방에서 혼자 기다려

**ライトな音聴かせて**  
라이토나 오토 키카세테  
가벼운 음악을 들려줘

**合図はエレキテルで**  
아이즈와 에레키테루데  
신호는 전기로

**白々しいほどちんけな**  
시라지라시이 호도 친케나  
뻔뻔할 만큼 보잘것없는

**歌は無視をして**  
우타와 무시오 시테  
노래는 무시하고

**なんかわかりかねる**  
난카 와카리카네루  
어쩐지 잘 모르겠어

**カエルも鳴く**  
카에루모 나쿠  
개구리도 울어

**おうちの鍵なら失くさないように持ってて**  
오우치노 카기나라 나쿠사나이 요오니 못테테  
집 열쇠라면 잃어버리지 않게 갖고 있어

**ほんとわかりかねる**  
혼토 와카리카네루  
정말 잘 모르겠어

**誰もおらず窓を開けたら**  
다레모 오라즈 마도오 아케타라  
아무도 없이 창문을 열면

**夕暮れの中、信号が何回も**  
유우구레노 나카, 신고오가 난카이모  
해 질 녘 속에서, 신호등이 몇 번이고

**変わる音を聞いてた**  
카와루 오토오 키이테타  
바뀌는 소리를 듣고 있었어

**向かいの田んぼ　隣の竹林も**  
무카이노 탄보 토나리노 치쿠린모  
맞은편 논 옆의 대숲도

**記憶の中じゃまだ、まだ**  
키오쿠노 나카쟈 마다, 마다  
기억 속에선 아직, 아직

**窓から入り込むモノの全部で**  
마도카라 하이리코무 모노노 젠부데  
창문으로 들어오는 것들 전부로

**肩身が狭くて壁に唾を吐く**  
카타미가 세마쿠테 카베니 츠바오 하쿠  
주눅이 들어 벽에 침을 뱉어

**なんかわかりかねる**  
난카 와카리카네루  
어쩐지 잘 모르겠어

**暇で踊る、割と楽しめる**  
히마데 오도루, 와리토 타노시메루  
심심해서 춤춰, 꽤 즐길 만해

**余白を何に使うの？**  
요하쿠오 나니니 츠카우노?  
여백을 뭐에 쓰는 거야?

**ちょっとわかりかける**  
춋토 와카리카케루  
조금 알 것 같아져

**冬が見える**  
후유가 미에루  
겨울이 보여

**窓を開けたら外から響く**  
마도오 아케타라 소토카라 히비쿠  
창문을 열면 밖에서 울려 퍼지는

**子どもが何回も笑う声を聞いてた**  
코도모가 난카이모 와라우 코에오 키이테타  
아이가 몇 번이고 웃는 소리를 듣고 있었어
