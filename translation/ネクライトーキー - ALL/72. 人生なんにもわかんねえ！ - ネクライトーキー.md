# 人生なんにもわかんねえ！

**ネクライトーキー**

---

**作词 : 朝日**  
작곡 : 朝日

**漂う埃がきらきら光った**  
타다요우 호코리가 키라키라 히캇타  
떠도는 먼지가 반짝반짝 빛났어

**午前の三時さ**  
고젠노 산지사  
오전 3시야

**ドブの色した電光板ずっと眺めたまんま**  
도부노 이로 시타 덴코오반 즛토 나가메타 만마  
시궁창 빛깔의 전광판을 계속 바라본 채로

**お揃いだね**  
오소로이다네  
똑같네

**「何かしなきゃ」なんて気持ちだけ**  
"나니카 시나캬" 난테 키모치다케  
"뭔가 해야 해"라는 마음만

**あるんだけど**  
아룬다케도  
있긴 한데

**そこかしこにあった筈の時間は何処へと行った**  
소코카시코니 앗타 하즈노 지칸와 도코에토 잇타  
여기저기 있었을 시간은 어디로 가버렸나

**窓から射す陽のせいでほら動かなきゃ**  
마도카라 사스 히노 세이데 호라 우고카나캬  
창으로 비치는 햇빛 탓에 봐 움직여야 해

**何処かへ行きたいな、今度こそ**  
도코카에 이키타이나, 콘도코소  
어딘가로 가고 싶어, 이번에야말로

**だって見なよ**  
닷테 미나요  
그야 봐봐

**月がまた俺を呼ぶんだ！**  
츠키가 마타 오레오 요분다!  
달이 또 나를 부르는 거야!

**わかんないようなこと**  
와칸나이 요오나 코토  
알 수 없는 것

**少しはわかりそうだったこと**  
스코시와 와카리소오닷타 코토  
조금은 알 것 같았던 것

**まとめてぐしゃぐしゃぐしゃぐしゃぐしゃぐしゃになって**  
마토메테 구샤구샤 구샤구샤 구샤구샤니 낫테  
한꺼번에 엉망진창 엉망진창 엉망진창이 돼서

**目が廻っちまうんです**  
메가 마왓치마운데스  
눈이 핑 돌아버려요

**ひとり泣きそうなこと**  
히토리 나키소오나 코토  
혼자 울 것 같은 것

**悔しくて声が出そうなこと**  
쿠야시쿠테 코에가 데소오나 코토  
분해서 소리가 날 것 같은 것

**全部がわかんないわかんないわかんなくなって**  
젠부가 와칸나이 와칸나이 와칸나쿠 낫테  
전부 모르겠어 모르겠어 모르게 돼서

**手に取っていくんです**  
테니 톳테이쿤데스  
손에 쥐어가요

**ただ向き合う**  
타다 무키아우  
그저 마주해

**中身は何だったろうなってふと首をひねった**  
나카미와 난닷타로오낫테 후토 쿠비오 히넷타  
속에 뭐가 있었더라 하고 문득 고개를 갸웃했어

**小さな箱を**  
치이사나 하코오  
작은 상자를

**いまだにずっと手放せないままなんだ**  
이마다니 즛토 테바나세나이 마마난다  
아직도 계속 놓지 못한 채야

**そんなもんだろ**  
손나 몬다로  
그런 거겠지

**誰もいないなんて好都合さ**  
다레모 이나이 난테 코오츠고오사  
아무도 없다니 안성맞춤이야

**ぐにゃぐにゃのアイラブユー**  
구냐구냐노 아이 라부 유우  
흐물흐물한 아이 러브 유

**何処かへ届いたらいいけどさ**  
도코카에 토도이타라 이이케도사  
어딘가에 닿으면 좋겠지만

**よく見りゃあボロボロの包みが惨めになって**  
요쿠 미랴아 보로보로노 츠츠미가 미지메니 낫테  
잘 보면 너덜너덜한 포장이 비참해져서

**笑っちまうんです**  
와랏치마운데스  
웃어버려요

**難しい、難しいな**  
무즈카시이, 무즈카시이나  
어려워, 어렵네

**まともになるのだって**  
마토모니 나루노닷테  
제대로 되는 것조차

**恥ずかしい、恥ずかしいな**  
하즈카시이, 하즈카시이나  
부끄러워, 부끄럽네

**理想を見るだなんて**  
리소오오 미루다 난테  
이상을 본다니

**正解だってもの見つけられたりするのかな**  
세이카이닷테 모노 미츠케라레타리 스루노카나  
정답이란 걸 찾아낼 수 있기는 할까

**…まぁとにかく歩かなきゃなあ**  
…마아 토니카쿠 아루카나캬나아  
…뭐 어쨌든 걸어야겠지

**わかんないようなこと**  
와칸나이 요오나 코토  
알 수 없는 것

**少しはわかりそうだったこと**  
스코시와 와카리소오닷타 코토  
조금은 알 것 같았던 것

**まとめてぐしゃぐしゃぐしゃぐしゃぐしゃぐしゃになって**  
마토메테 구샤구샤 구샤구샤 구샤구샤니 낫테  
한꺼번에 엉망진창 엉망진창 엉망진창이 돼서

**また日和っちまうんです**  
마타 히욧치마운데스  
또 꽁무니를 빼버려요

**大事にしたいことも**  
다이지니 시타이 코토모  
소중히 하고 싶은 것도

**声に出せずに飲み込んだこと**  
코에니 다세즈니 노미콘다 코토  
소리 내지 못하고 삼킨 것

**全部がわかんないわかんないわかんなくたって**  
젠부가 와칸나이 와칸나이 와칸나쿠탓테  
전부 모르겠어 모르겠어 모르더라도

**手に取っていくんです**  
테니 톳테이쿤데스  
손에 쥐어가요

**また向き合う**  
마타 무키아우  
다시 마주해
