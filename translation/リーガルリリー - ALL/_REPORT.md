## 해결 이력

검수 방법: 각 파일의 작사/작곡 크레딧 대조. 커버곡 7곡을 제외한 나머지는 전부 `たかはしほのか` 단독 크레딧.

### 16. ムスタング — 확인 완료 (AKG TRIBUTE 커버, 오수집 아님)

- 크레딧: 작사 `後藤正文` / 작곡 `後藤正文・山田貴洋` (ASIAN KUNG-FU GENERATION 원곡자).
- 실제로는 リーガルリリー가 2017년 AKG TRIBUTE 앨범(AKFG 20주년 트리뷰트)에 수록한 정식 커버. 오수집이 아니라 원곡자 크레딧 표기가 맞는 케이스.
- 크레딧은 원곡자 표기 그대로 유지, "(cover)" 등 별도 표기는 하우스 스타일상 추가하지 않음 (Ado - ALL의 커버 수록곡과 동일 컨벤션).

### 39. 天使と悪魔 — 확인 완료 (SEKAI NO OWARI 커버, 오수집 아님)

- 크레딧: 작사・작곡 `深瀬慧` (SEKAI NO OWARI 원곡자).
- リーガルリリー가 2021년 EP『the World』에 수록한 정식 커버 (たかはしほのか가 10대 시절 좋아했던 곡을 7년 만에 커버). 원곡 SEKAI NO OWARI 버전(uta-net/104108)과 가사 자체는 동일하나, 올바른 소스는 リーガルリリー 아티스트 페이지(uta-net/300623)로 교체.
- 기존 파일 내용이 이미 정확했음 (오탐지) — 재검증 후 그대로 확정.

### 37. ベッドタウン — 확인 완료 (분량 미달 아님)

- 크레딧 `たかはしほのか` 정상. 3개 독립 소스(uta-net 검색 스니펫, utaten, j-lyric.net)로 대조한 결과 전체 6줄짜리 짧은 인터루드 트랙으로 확인 — 기존 파일이 이미 완전한 상태였음.
- 마지막 두 줄(`…のままでいて！` / `…のままで。`)은 실제로 둘 다 존재하는 의도적 반복(다른 어미)이며 절단이 아니었음.
