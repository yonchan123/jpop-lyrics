# 風にとどけ

**リーガルリリー**

---

**作词 : たかはしほのか**  
작곡 : たかはしほのか

**向かい風の中で、心はどっかいったんだ。**  
무카이카제노 나카데 코코로와 돗카 잇탄다  
맞바람 속에서 마음은 어딘가로 가 버렸어

**すきま風とともに、気付かぬうちに。**  
스키마카제토 토모니 키즈카누 우치니  
틈새 바람과 함께 알아차리지 못한 사이에

**向かい風の中で、心はどっかいったんだ。**  
무카이카제노 나카데 코코로와 돗카 잇탄다  
맞바람 속에서 마음은 어딘가로 가 버렸어

**あなたのためいきに、背中押されて。**  
아나타노 타메이키니 세나카 오사레테  
당신의 한숨에 등 떠밀려서

**流されてくのは形だけ　優しい顔　思い出した**  
나가사레테쿠노와 카타치다케 야사시이 카오 오모이다시타  
떠내려가는 건 형태뿐 다정한 얼굴을 떠올렸어

**会いたいや　気持ちで愛を知る心が**  
아이타이야 키모치데 아이오 시루 코코로가  
보고 싶어라 마음으로 사랑을 아는 가슴이

**おかしくて　おかしくて　涙が出そうだ**  
오카시쿠테 오카시쿠테 나미다가 데소오다  
우스워서 우스워서 눈물이 날 것 같아

**涙が出そう**  
나미다가 데소오  
눈물이 날 것 같아

**向かい風の中で、僕を保っていたんだ。**  
무카이카제노 나카데 보쿠오 타못테이탄다  
맞바람 속에서 나를 지탱하고 있었어

**蝶番のメロディ、思い出す。**  
쵸오츠가이노 메로디 오모이다스  
경첩의 멜로디를 떠올려

**二人乗りの自転車　追い風に逆らったまま　あの日**  
후타리노리노 지텐샤 오이카제니 사카랏타 마마 아노 히  
둘이 탄 자전거 순풍을 거스른 채로 그날

**流されてく命の流れ　この街の癖なんだね**  
나가사레테쿠 이노치노 나가레 코노 마치노 쿠세난다네  
떠내려가는 생명의 흐름 이 거리의 버릇이구나

**会えないや　気持ちで愛を知る心が**  
아에나이야 키모치데 아이오 시루 코코로가  
만날 수 없어라 마음으로 사랑을 아는 가슴이

**おかしくて　おかしくて　涙が出そう**  
오카시쿠테 오카시쿠테 나미다가 데소오  
우스워서 우스워서 눈물이 날 것 같아

**君がいない場所で　愛の歌　唄えば**  
키미가 이나이 바쇼데 아이노 우타 우타에바  
네가 없는 곳에서 사랑의 노래를 부르면

**楽しくて　楽しくて　涙が出そうだ**  
타노시쿠테 타노시쿠테 나미다가 데소오다  
즐거워서 즐거워서 눈물이 날 것 같아

**涙が出そうだ**  
나미다가 데소오다  
눈물이 날 것 같아

**向かい風の中で、心はどっかいったんだ。**  
무카이카제노 나카데 코코로와 돗카 잇탄다  
맞바람 속에서 마음은 어딘가로 가 버렸어

**あなたのためいきに、気付かぬうちに。**  
아나타노 타메이키니 키즈카누 우치니  
당신의 한숨에 알아차리지 못한 사이에
