# きれいなおと

**リーガルリリー**

---

**作词 : たかはしほのか**  
작곡 : たかはしほのか

**時代を乗り越えられない僕だった**  
지다이오 노리코에라레나이 보쿠닷타  
시대를 넘어서지 못하는 나였다

**時間を乗り越えられないって焦っている**  
지칸오 노리코에라레나잇테 아셋테이루  
시간을 넘어서지 못한다며 초조해하고 있어

**落ち着かなければ重い荷物だって**  
오치츠카나케레바 오모이 니모츠닷테  
침착하지 않으면 무거운 짐이라도

**落として割ってしまう**  
오토시테 왓테시마우  
떨어뜨려 깨버려

**あのころはよかったな。**  
아노 코로와 요캇타나  
그때는 좋았지.

**なにをしても今だから。**  
나니오 시테모 이마다카라  
무엇을 해도 지금이니까.

**ハイな気持ちを続けて鳴らせれば、きれいなおとになる。**  
하이나 키모치오 츠즈케테 나라세레바 키레이나 오토니 나루  
들뜬 기분을 계속 울려 낼 수 있다면, 아름다운 소리가 돼.

**なつかしい寂しさが。**  
나츠카시이 사미시사가  
그리운 쓸쓸함이.

**ふと口ずさんだ可愛いメロディも**  
후토 쿠치즈산다 카와이이 메로디모  
문득 흥얼거린 귀여운 멜로디도

**時間を乗りこえようとして叫んでいる**  
지칸오 노리코에요오토 시테 사켄데이루  
시간을 넘어서려고 외치고 있어

**落ち着かなければ重い体だって**  
오치츠카나케레바 오모이 카라다닷테  
침착하지 않으면 무거운 몸이라도

**落として割ってしまう**  
오토시테 왓테시마우  
떨어뜨려 깨버려

**奥行きは見えないさ。**  
오쿠유키와 미에나이사  
깊이는 보이지 않아.

**僕の自信よ、満ちてゆけ。**  
보쿠노 지신요 미치테 유케  
나의 자신감이여, 가득 차올라라.

**変わらない場所　君のいれもの**  
카와라나이 바쇼 키미노 이레모노  
변하지 않는 곳 너의 그릇

**君が夢を忘れてしまっても**  
키미가 유메오 와스레테시맛테모  
네가 꿈을 잊어버려도

**ハイな気持ちを続けて鳴らせれば、きれいなおとになる。**  
하이나 키모치오 츠즈케테 나라세레바 키레이나 오토니 나루  
들뜬 기분을 계속 울려 낼 수 있다면, 아름다운 소리가 돼.

**やさしさが、温もりが。**  
야사시사가 누쿠모리가  
다정함이, 온기가.
