# ハナヒバナ

**Pastel*Palettes**

---

**作词 : 织田あすか(Elements Garden)**  
작곡 : 日高勇輝(Elements Garden)

**同じ季節も同じ景色には**  
오나지 키세츠모 오나지 케시키니와  
같은 계절도 같은 풍경에는

**二度と巡り会えなくて**  
니도토 메구리아에나쿠테  
두 번 다시 만날 수 없어서

**スルリと離れてゆく　いつの間にか**  
스루리토 하나레테 유쿠 이츠노마니카  
스르르 멀어져 가 어느샌가

**こんなにも大きくなって**  
콘나니모 오오키쿠 낫테  
이렇게나 커져서

**(キラキラと)**  
(키라키라토)  
(반짝반짝)

**照らされるほど**  
테라사레루 호도  
비춰질수록

**(はらはらと)**  
(하라하라토)  
(조마조마)

**本音が零れてく**  
혼네가 코보레테쿠  
속마음이 흘러넘쳐

**(大切な)**  
(타이세츠나)  
(소중한)

**ありがとう　きみへ**  
아리가토오 키미에  
고마워 너에게

**刹那につぶやく**  
세츠나니 츠부야쿠  
찰나에 중얼거려

**まばゆく咲いて　儚く消えた**  
마바유쿠 사이테 하카나쿠 키에타  
눈부시게 피어 덧없이 사라졌어

**夜空いっぱい　熱い音色で**  
요조라 잇파이 아츠이 네이로데  
밤하늘 가득 뜨거운 음색으로

**何度も　響かせて　想いの全てを**  
난도모 히비카세테 오모이노 스베테오  
몇 번이고 울려서 마음의 전부를

**少しの寂しさも**  
스코시노 사미시사모  
약간의 쓸쓸함도

**打ち上がるたび　もっと高くへ**  
우치아가루 타비 못토 타카쿠에  
쏘아 올라갈 때마다 더 높이

**包み込むよう　輝きながら**  
츠츠미코무 요오 카가야키나가라  
감싸안듯이 빛나면서

**終わりが　始まりを　導いてくように**  
오와리가 하지마리오 미치비이테쿠 요오니  
끝이 시작을 이끌어 가듯이

**散れば　また開く**  
치레바 마타 히라쿠  
지면 또 피어나는

**わたしたちの花**  
와타시타치노 하나  
우리의 꽃

**全ては移ろうもの**  
스베테와 우츠로우 모노  
모든 것은 변해 가는 것

**また一つ　思い出が増えてゆくね**  
마타 히토츠 오모이데가 후에테 유쿠네  
또 하나 추억이 늘어 가네

**にがくてあまい　かけがえのないもの**  
니가쿠테 아마이 카케가에노나이 모노  
쓰고도 달콤한 둘도 없는 것

**叶うなら　も一度触れたい**  
카나우나라 모 이치도 후레타이  
가능하다면 한 번 더 닿고 싶어

**(キラキラと)**  
(키라키라토)  
(반짝반짝)

**切なさの中**  
세츠나사노 나카  
애틋함 속

**(ゆらゆらと)**  
(유라유라토)  
(흔들흔들)

**愛しさを抱いては**  
이토시사오 다이테와  
사랑스러움을 안고서

**(いつまでも)**  
(이츠마데모)  
(언제까지나)

**昇り続けよう**  
노보리 츠즈케요오  
계속 올라가자

**夢の階段を**  
유메노 카이단오  
꿈의 계단을

**まばゆく咲いて　儚く消えた**  
마바유쿠 사이테 하카나쿠 키에타  
눈부시게 피어 덧없이 사라졌어

**夜空いっぱい　悔いのないように**  
요조라 잇파이 쿠이노나이 요오니  
밤하늘 가득 후회 없도록

**5つの　色々で　弾け合いながら**  
이츠츠노 이로이로데 하지케아이나가라  
다섯 색깔로 서로 터지면서

**美しい形へ**  
우츠쿠시이 카타치에  
아름다운 형태로

**変わり続ける　景色の中で**  
카와리 츠즈케루 케시키노 나카데  
계속 변해 가는 풍경 속에서

**きみのことを　変わらず想う**  
키미노 코토오 카와라즈 오모우  
너를 변함없이 생각해

**季節が　巡り来る　そのたびに強く**  
키세츠가 메구리쿠루 소노 타비니 츠요쿠  
계절이 돌아올 때마다 강하게

**胸に焼き付けよう**  
무네니 야키츠케요오  
가슴에 새겨두자

**わたしたちの花**  
와타시타치노 하나  
우리의 꽃

**横顔に　今　笑顔が咲いた**  
요코가오니 이마 에가오가 사이타  
옆모습에 지금 미소가 피었어

**わたしだけの花火がここに**  
와타시다케노 하나비가 코코니  
나만의 불꽃이 여기에

**どんなに　遠くまで　歩いて来ようとも**  
돈나니 토오쿠마데 아루이테 코요오토모  
아무리 멀리까지 걸어왔다 해도

**繋ぐ手は　このまま**  
츠나구 테와 코노마마  
잡은 손은 이대로

**打ち上がるたび　もっと高くへ**  
우치아가루 타비 못토 타카쿠에  
쏘아 올라갈 때마다 더 높이

**包み込むよう　輝きながら**  
츠츠미코무 요오 카가야키나가라  
감싸안듯이 빛나면서

**終わりが　始まりを　導いてくように**

끝이 시작을 이끌어 가듯이
