# 扇子

**大塚愛**

---

**作词 : 愛**  
작곡 : 愛

**涙は幾ら流しても止まらないの**  
나미다와 이쿠라 나가시테모 토마라나이노  
눈물은 아무리 흘려도 멈추지 않아

**どれだけ扇いでも乾かない**  
도레다케아오이데모 카와카나이  
아무리 부채질해도 마르지 않아

**でもね 決して見られちゃいけないの**  
데모네 켓시테 미라레차이케나이노  
그래도 절대 들켜선 안 돼

**私は強い子なんだから**  
와타시와 츠요이코난다카라  
나는 강한 아이니까

**ちょっと 躓いたよね**  
촛토 츠마즈이타요네  
조금 걸려 넘어졌지

**ちょっと 失敗したよね**  
촛토 싯파이시타요네  
조금 실수했지

**あぁ、こんなに晴れちゃ 声あげて泣けないよ**  
아아, 콘나니 하레차 코에아게테 나케나이요  
아아, 이렇게 맑으면 소리 내어 울 수도 없어

**ちょっと 愚痴をこぼした**  
촛토 구치오코보시타  
조금 푸념을 늘어놓았어

**ちょっと 言い訳した**  
촛토 이이와케시타  
조금 변명했어

**あぁ、にっこりした風よ 優しく抱きしめて**  
아아, 닛코리시타 카제요 야사시쿠다키시메테  
아아, 방긋 웃는 바람아, 다정하게 안아 줘

**唇 とんがらせて 大きい靴引き摺って**  
쿠치비루 톤가라세테 오오키이쿠츠히키즛테  
입술 삐죽 내밀고 커다란 신발 질질 끌며

**暑いのに太陽で私を刺すのね**  
아츠이노니 타이요오데 와타시오 사스노네  
더운데 햇볕까지 나를 찔러 대네

**腕が痛くなるくらい扇いで**  
우데가 이타쿠나루쿠라이아오이데  
팔이 아파질 만큼 부채질해서

**誰にも顔がみえないくらい**  
다레니모 카오가미에나이쿠라이  
누구에게도 얼굴이 안 보일 만큼

**ちょっと 躓いたよね**  
촛토 츠마즈이타요네  
조금 걸려 넘어졌지

**ちょっと 失敗したよね**  
촛토 싯파이시타요네  
조금 실수했지

**あぁ、こんなに暖かいと 見上げちゃうよ**  
아아, 콘나니 아타타카이토 미아게차우요  
아아, 이렇게 따뜻하면 올려다보게 되잖아

**ちょっと 愚痴をこぼした**  
촛토 구치오코보시타  
조금 푸념을 늘어놓았어

**ちょっと 言い訳した**  
촛토 이이와케시타  
조금 변명했어

**あぁ、笑顔の香りで 優しく抱きしめて**  
아아, 에가오노 카오리데 야사시쿠다키시메테  
아아, 웃음의 향기로 다정하게 안아 줘
