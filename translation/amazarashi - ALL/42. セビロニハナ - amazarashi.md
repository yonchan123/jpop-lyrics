# セビロニハナ

**amazarashi**

---

**作词 : 秋田ひろむ**  
작곡 : 秋田ひろむ

**鈍感さは強さとして**  
돈칸사와 츠요사토 시테  
둔감함은 강함이라 치고

**昨日までの様々は 過ぎた景色と振り返らず**  
키노오마데노 사마자마와 스기타 케시키토 후리카에라즈  
어제까지의 여러 일은 지나간 풍경이라며 돌아보지 않고

**敏感さは弱さとして**  
빈칸사와 요와사토 시테  
예민함은 약함이라 치고

**誰も眼にくれない 人混みの機微に傷ついて**  
다레모 메니 쿠레나이 히토고미노 키비니 키즈츠이테  
아무도 눈길 주지 않는 인파 속 미묘한 기척에 상처 입고

**瞬間 突風吹き抜けて**  
슌칸 톳푸우 후키누케테  
순간 돌풍이 휘몰아쳐

**背広の襟に張り付く花に**  
세비로노 에리니 하리츠쿠 하나니  
양복 깃에 달라붙은 꽃을

**気付く人など少ないが**  
키즈쿠 히토나도 스쿠나이가  
알아채는 사람은 별로 없지만

**気付いた君が都市を行く**  
키즈이타 키미가 토시오 유쿠  
알아챈 네가 도시를 걸어가

**痛みを知った 足取りで**  
이타미오 싯타 아시도리데  
아픔을 아는 걸음걸이로

**恥ずかしそうに都市を行く**  
하즈카시소오니 토시오 유쿠  
부끄러운 듯 도시를 걸어가

**君に張り付く花びらが**  
키미니 하리츠쿠 하나비라가  
너에게 달라붙은 꽃잎이

**君の名前を語ってる**  
키미노 나마에오 카탓테루  
너의 이름을 말해 주고 있어
