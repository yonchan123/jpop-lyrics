# Fateful...

**Morfonica**

**作词 : 織田あすか(Elements Garden)**  
작곡 : 上松範康(Elements Garden)

**出会いが告げた すべての始まりを**

**芽吹く思いに 扉はひらく**  
메부쿠 오모이니 토비라와 히라쿠

나니 히토츠 우타가와즈니 신지루 마마니

한 방울 흔들린 수면이 보여준

**新たな世界を 強く抱きしめて**

새로운 세계를 강하게 끌어안고

**後悔せずに 今日も生きてゆく**  
코오카이세즈니 쿄오모 이키테 유쿠  
후회하지 않고 오늘도 살아가

**懸命に一つ一つ 結んでゆこう**

열심히 하나하나 맺어가자

**不器用でも構わないんだ**

서툴러도 상관없어

**季節ごと 時間ごとに それは優しく**

**風は 背中を押してゆく**
