# 宝者

**AiNA THE END**

**ありがとう 宝者**    
아리가또 타카라모노    
고마워, 소중한 사람  

**掠れずに伝えたい**    
카스레즈니 츠타에타이    
마음이 닿도록 전하고 싶어  

**温かいこころをくれたね**    
아타타카이 코코로오 쿠레타네    
따뜻한 마음을 줬지  

**背中撫でるように**    
세나카 나데루 요오니    
등을 쓸어주듯이  

**さよならね 宝者**    
사요나라네 타카라모노    
안녕이야, 소중한 사람  

**さすらいの猫のように**    
사스라이 노 네코 노 요오니    
방랑하는 고양이처럼  

**わたしも自由に歩いていくわ**    
와타시모 지유우니 아루이테이쿠와    
나도 자유롭게 걸어갈 거야  

**行かなきゃね いつかの約束**    
이카나캬네 이츠카노 약소쿠    
가야겠지, 언젠가의 약속  

**夜明けに泣きついた**    
요아케니 나키츠이타    
새벽에 울음을 터뜨렸어  

**ほんとは素直でいたいの**    
혼토와 스나오데 이타이노    
사실은 솔직하고 싶어  

**あやして去らないで**    
아야시테 사라나이데    
달래고 떠나지 말아줘  

**つよがりの私です**    
츠요가리노 와타시데스    
강한 척하는 나야  

**自信ない音 宙に舞ってる**    
지신나이 오토 츄우니 맛테루    
자신 없는 소리가 공중에 떠다니고 있어  

**あなたいつも 見透かしている**    
아나타이츠모 미스카시테이루    
당신은 항상 꿰뚫어 보고 있어  

**馴染みある音 触れてくれる**    
나지미아루 오토 후레테쿠레루    
익숙한 소리를 건드려줘  

**あなたいつも そばにいてくれたね**    
아나타이츠모 소바니 이테쿠레타네    
당신은 항상 내 곁에 있어줬지  

**ありがとう 宝者**    
아리가또 타카라모노    
고마워, 소중한 사람  

**きえないさ滲んでる**    
키에나이사 니진데루    
지워지지 않고 번지고 있어  

**もらった言葉をぎゅってして**    
모랏타 코토바오 귯테시테    
받은 말을 꼭 붙잡고  

**音にする旅よさよならね 宝者**    
오토니 스루 타비요 사요나라네 타카라모노    
음악으로 바꾸는 여행이야 안녕이야, 소중한 사람  

**不甲斐なく空を見る**    
후가이나쿠 소라오 미루    
한심하게 하늘을 봐  

**まだ少し寂しい模様だけど**    
마다 스코시 사비시이 모요오다케도    
아직 조금 쓸쓸한 듯하지만  

**行かなきゃね いつかの約束**    
이카나캬네 이츠카노 약소쿠    
가야겠지, 언젠가의 약속  

**『星見えなくなった』と思えば**    
『호시 미에나쿠낫타』토 오모에바    
'별이 안 보인다'고 생각하면  

**目が悪くなっただけだったみたいだ**    
메가 와루쿠 낫타 다케닷타미타이다    
눈이 나빠졌을 뿐인 것 같아  

**変わりゆくのは自分**    
카와리유쿠 노와 지분    
변해가는 건 자신  

**至らない音 くすんだ日々**    
이타라나이 오토 쿠슨다 히비    
미흡한 소리, 흐릿한 나날들  

**あなたいつも 見透かしていた**    
아나타이츠모 미스카시테이타    
당신은 항상 꿰뚫어 보고 있었어  

**確かな音 守られた日々**    
타시카나 오토 마모라레타 히비    
분명한 소리, 지켜졌던 나날들  

**忘れないように 変わらないままいたい**    
와스레나이 요오니 카와라나이 마마 이타이    
잊지 않도록 변하지 않고 싶어  

**なんて考えていたっけ**    
난테 캉가에테 이탓케    
뭘 생각하고 있었더라  

**なんで歩いてんだっけ**    
난데 아루이텐 닷케    
왜 걷고 있는 거지  

**立ち返るその度に**    
타치카에루 소노 타비니    
돌아갈 때마다  

**柔らかい記憶**    
야와라카이 키오쿠    
부드러운 기억  

**大事だった 大事だった**    
다이지닷타 다이지닷타    
소중했어, 소중했어

토도케니 이카나캬    
전하러 가야 해
