# 傷

**Conton Candy**

---

**作词 : Conton Candy**  
작곡 : Conton Candy  
편곡 : Conton Candy

**30分、本気でつけた傷**  
산줏푼, 혼키데 츠케타 키즈  
30분 동안 진심으로 낸 상처

**それだけは愛せるのに**  
소레다케와 아이세루노니  
그것만은 사랑할 수 있는데

**一瞬でつけられたお前からの**  
잇슌데 츠케라레타 오마에카라노  
한순간에 새겨진 너로부터의

**傷だけは愛せない**  
키즈다케와 아이세나이  
상처만은 사랑할 수 없어

**まっすぐ生きることに**  
맛스구 이키루 코토니  
똑바로 살아가는 것에

**少し自信がなくなる日々です**  
스코시 지신가 나쿠나루 히비데스  
조금 자신이 없어지는 나날입니다

**それでもここに立つために**  
소레데모 코코니 타츠 타메니  
그래도 여기에 서기 위해

**歌を歌っているのです**  
우타오 우탓테 이루노데스  
노래를 부르고 있는 것입니다

**私の言葉になってくれて**  
와타시노 코토바니 낫테 쿠레테  
내 말이 되어 줘서

**なんやかんやさんきゅー!(笑)**  
난야칸야 산큐우! (와라)  
이러니저러니 해도 땡큐! (웃음)
