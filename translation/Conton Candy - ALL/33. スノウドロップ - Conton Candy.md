# スノウドロップ

**Conton Candy**

---

**作词 : Conton Candy**  
작곡 : Conton Candy  
편곡 : Conton Candy

**空を仰いでる**  
소라오 아오이데루  
하늘을 올려다보고 있어

**転がった秒針と**  
코로갓타 뵤오신토  
굴러떨어진 초침과

**孤独に埋もれた部屋に響くインターホン**  
코도쿠니 우모레타 헤야니 히비쿠 인타아혼  
고독에 파묻힌 방에 울리는 인터폰

**このままじゃダメだとして**  
코노 마마쟈 다메다토시테  
이대로는 안 된다고 해도

**でもこのままで居られるように**  
데모 코노 마마데 이라레루 요오니  
그래도 이대로 있을 수 있도록

**止ることをやめないで**  
토도마루 코토오 야메나이데  
머무르는 걸 그만두지 마

**開く**  
히라쿠  
피어나

**伝えたい気持ちは僕に**  
츠타에타이 키모치와 보쿠니  
전하고 싶은 마음은 나에게

**舌が無くてもこんなに伝わってる**  
시타가 나쿠테모 콘나니 츠타왓테루  
혀가 없어도 이렇게나 전해지고 있어

**掴みたい幸せだって**  
츠카미타이 시아와세닷테  
붙잡고 싶은 행복이라는 것도

**一瞬香った花のように枯れないもの**  
잇슌 카옷타 하나노 요오니 카레나이 모노  
한순간 향기 났던 꽃처럼 시들지 않는 것

**探して 彷徨って 生きる**  
사가시테 사마욧테 이키루  
찾고 헤매며 살아가

**もう現実と空想で渋滞**  
모오 겐지츠토 쿠우소오데 쥬우타이  
이미 현실과 공상으로 꽉 막혀 있어

**なんやかんや眠ったら安泰**  
난야칸야 네뭇타라 안타이  
이러니저러니 해도 자고 나면 괜찮아

**そうでもないような日もある**  
소오데모 나이 요오나 히모 아루  
그렇지도 않은 날도 있어

**あるんだよ**  
아룬다요  
있는 거야

**この先あるのは可能性**  
코노 사키 아루노와 카노오세이  
이 앞에 있는 건 가능성

**心配ご無用 未完成でもいけ**  
신파이 고무요오 미칸세이데모 이케  
걱정은 필요 없어, 미완성이라도 가 버려

**伝えたい気持ちがあって**  
츠타에타이 키모치가 앗테  
전하고 싶은 마음이 있어서

**今こうして書き綴ってみるけど**  
이마 코오시테 카키츠즛테 미루케도  
지금 이렇게 써 내려가 보지만

**掴みたいそれは君の心**

붙잡고 싶은 그건 너의 마음
