# レイドバックジャーニー

**CANDY TUNE**

---

**作词 : つむぎしゃち・久下真音**  
작곡 : 久下真音

**どこへゆこう？**  
도코에 유코오?  
어디로 갈까?

**どこでもゆこう**  
도코데모 유코오  
어디든 가자

**すばらしい　ゆるゆるしい**  
스바라시이 유루유루시이  
멋지고 느긋느긋해

**僕らの旅へ**  
보쿠라노 타비에  
우리들의 여행으로

**考えても　わからないことも**  
캉가에테모 와카라나이 코토모  
생각해도 알 수 없는 것도

**風にちょっと聞いてみる**  
카제니 춋토 키이테미루  
바람에게 살짝 물어봐

**えーっと　なにか忘れものないかなぁ？**  
에엣토 나니카 와스레모노 나이카나아?  
음 뭔가 잊은 물건 없으려나?

**カバンに詰め込むスキレット**  
카반니 츠메코무 스키렛토  
가방에 채워 넣는 스킬렛

**あれもこれも入れてくの**  
아레모 코레모 이레테쿠노  
저것도 이것도 넣어가는 거야

**ねぇ　心やわらかリュブリカント**  
네에 코코로 야와라카 류브리칸토  
있잖아 마음 부드러운 윤활제

**シェラカップに足す夢を　ひとつ**  
셰라캇푸니 타스 유메오 히토츠  
시에라컵에 더하는 꿈을 하나

**みんな集まって**  
민나 아츠맛테  
모두 모여서

**あたたかい火が待っている**  
아타타카이 히가 맛테이루  
따뜻한 불이 기다리고 있어

**ゆこう 1234 ここから君と歩いてこう**  
유코오 완 투 스리 포 코코카라 키미토 아루이테코오  
가자 1234 여기서 너와 걸어가자

**ココロの呼ぶ声をきいて**  
코코로노 요부 코에오 키이테  
마음이 부르는 소리를 듣고

**たどりついた場所から**  
타도리츠이타 바쇼카라  
다다른 곳에서

**最高を描こう**  
사이코오오 에가코오  
최고를 그리자

**ここはまだ道のトチュウ**  
코코와 마다 미치노 토츄우  
여기는 아직 길의 도중

**ほらLucky Lucky Lucky　小さな一歩**  
호라 Lucky Lucky Lucky 치이사나 잇포  
봐 Lucky Lucky Lucky 작은 한 걸음

**Lucky Lucky　なに持ってこう？**  
Lucky Lucky 나니 못테코오?  
Lucky Lucky 뭘 가져갈까?

**もっとLucky Lucky Lucky　風のさきっぽ**  
못토 Lucky Lucky Lucky 카제노 사킷포  
더 Lucky Lucky Lucky 바람의 끝자락

**Lucky Lucky　まだまだ旅は続く**  
Lucky Lucky 마다마다 타비와 츠즈쿠  
Lucky Lucky 아직도 여행은 계속돼

**雨降りそう？**  
아메 후리소오?  
비 올 것 같아?

**まだ平気そう**  
마다 헤이키소오  
아직 괜찮을 것 같아

**なんだかめまぐるしい**  
난다카 메마구루시이  
왠지 어수선해

**今日の空模様**  
쿄오노 소라모요오  
오늘의 하늘 모양

**考えたら出てきた答えも**  
캉가에타라 데테키타 코타에모  
생각하니 나온 답도

**やっぱりちょっと違うかも**  
얏파리 춋토 치가우카모  
역시 좀 다를지도

**時間を忘れて**  
지칸오 와스레테  
시간을 잊고

**あたたかい火　ながめてみる**  
아타타카이 히 나가메테미루  
따뜻한 불을 바라봐

**いつも 1234 行ったり来たり歩いてこう**  
이츠모 완 투 스리 포 잇타리 키타리 아루이테코오  
언제나 1234 왔다 갔다 걸어가자

**ねころんだら深呼吸して**

드러누우면 심호흡하고

**登りきったとこがきっと**

**ちょうど真ん中**
