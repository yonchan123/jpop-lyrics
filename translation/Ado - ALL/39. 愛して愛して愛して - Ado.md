# 愛して愛して愛して

**Ado**

---

**作词 : きくお**  
작곡 : きくお

**はるか遠い遠い昔　巻かれた首輪**  
하루카 토오이 토오이 무카시 마카레타 쿠비와  
아득히 먼 먼 옛날 채워진 목줄

**人が欲しい人が欲しいと叫ぶ　呪いの首輪**  
히토가 호시이 히토가 호시이토 사케부 노로이노 쿠비와  
사람이 갖고 싶어 사람이 갖고 싶다고 외치는 저주의 목줄

**怒らないで見捨てないで　どこもいかないで　(ねえ)**  
오코라나이데 미스테나이데 도코모 이카나이데 (네에)  
화내지 마 버리지 마 어디도 가지 마 (있잖아)

**強く絞める吐くまで絞める　人がいないいないと**  
츠요쿠 시메루 하쿠마데 시메루 히토가 이나이 이나이토  
강하게 조여 토할 때까지 조여 사람이 없어 없다고

**いい成績でしょ　ねえ　ねえ　いい子でしょ**  
이이 세이세키데쇼 네에 네에 이이코데쇼  
좋은 성적이지 있잖아 있잖아 착한 아이지

**かわいい子でしょ　ねえ　ねえ　良い子でしょう　苦しい　ねえ**  
카와이이 코데쇼 네에 네에 이이코데쇼오 쿠루시이 네에  
귀여운 아이지 있잖아 있잖아 착한 아이지 괴로워 있잖아

**愛して　愛して　愛して　もっともっと　愛して　愛して　狂おしいほどに**  
아이시테 아이시테 아이시테 못토 못토 아이시테 아이시테 쿠루오시이 호도니  
사랑해 줘 사랑해 줘 사랑해 줘 더 더 사랑해 줘 사랑해 줘 미칠 만큼

**苦しい　苦しい　呪縛を　解いて解いて　ねえ　止められない　嗚呼**  
쿠루시이 쿠루시이 쥬바쿠오 토이테 토이테 네에 토메라레나이 아아  
괴로워 괴로워 주박을 풀어 줘 풀어 줘 있잖아 멈출 수 없어 아아

**身体　身体　大きくなっても小さい首輪**  
카라다 카라다 오오키쿠 낫테모 치이사이 쿠비와  
몸 몸 커져도 작은 목줄

**苦しくなる足りなくなる　人が　人が　足りない**  
쿠루시쿠 나루 타리나쿠 나루 히토가 히토가 타리나이  
괴로워져 모자라져 사람이 사람이 모자라

**クラスの誰にも負けない　キレイないい子でしょう　(ねえ)**  
쿠라스노 다레니모 마케나이 키레이나 이이코데쇼오 (네에)  
반의 누구에게도 지지 않아 예쁘고 착한 아이지 (있잖아)

**あの子よりもどの子よりも　誰も彼も私を見てよ**  
아노 코요리모 도노 코요리모 다레모 카레모 와타시오 미테요  
저 아이보다도 어느 아이보다도 누구나 다 나를 봐 줘

**体育館裏　あなたに告白を**  
타이이쿠칸 우라 아나타니 코쿠하쿠오  
체육관 뒤편 당신에게 고백을

**嘘みたいでしょ　あなたが好きなの　汚いあなたが**  
우소미타이데쇼 아나타가 스키나노 키타나이 아나타가  
거짓말 같지 당신을 좋아해 더러운 당신을

**愛して　愛して　愛して　全部あげる**  
아이시테 아이시테 아이시테 젬부 아게루  
사랑해 줘 사랑해 줘 사랑해 줘 전부 줄게

**あなたに　あなたに　全部背負ってもらうよ**  
아나타니 아나타니 젬부 세옷테 모라우요  
당신에게 당신에게 전부 짊어지게 할 거야

**足りない　あなたが　足りない　離さないよ　嗚呼　ごめんなさい**  
타리나이 아나타가 타리나이 하나사나이요 아아 고멘나사이  
모자라 당신이 모자라 놓아주지 않을 거야 아아 미안해요

**愛して　愛して　愛して　もっともっと　愛して　愛して　狂おしいほどに**  
아이시테 아이시테 아이시테 못토 못토 아이시테 아이시테 쿠루오시이 호도니  
사랑해 줘 사랑해 줘 사랑해 줘 더 더 사랑해 줘 사랑해 줘 미칠 만큼

**苦しい　離さない　苦しい　もっともっと　ねえ　幸せなの　嗚呼**  
쿠루시이 하나사나이 쿠루시이 못토 못토 네에 시아와세나노 아아  
괴로워 놓지 않을 거야 괴로워 더 더 있잖아 행복해 아아

**幸せなの　嗚呼**  
시아와세나노 아아  
행복해 아아
