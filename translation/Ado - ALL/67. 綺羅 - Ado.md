# 綺羅

**Ado**

---

**作词 : キタニタツヤ**  
작곡 : キタニタツヤ

**もう幾度、幾十度噛んだ下唇に**  
모오 이쿠도, 이쿠쥬우도 칸다 시타쿠치비루니  
이미 몇 번, 몇 십 번 깨문 아랫입술에

**滲んだ鉄の味、もう飽き飽きしている**  
니진다 테츠노 아지, 모오 아키아키시테이루  
배어든 쇠의 맛, 이미 진절머리가 나

**薄闇の海を見つめている**  
우스야미노 우미오 미츠메테이루  
어스름한 바다를 바라보고 있어

**誰かが囁くのが聞こえる**  
다레카가 사사야쿠노가 키코에루  
누군가가 속삭이는 게 들려

**「もっと先へ、もっと自由に、**  
「못토 사키에, 못토 지유우니,  
「더 앞으로, 더 자유롭게,

**まだ知らない場所へ」**  
마다 시라나이 바쇼에」  
아직 모르는 곳으로」

**綺羅、身に纏った綺羅**  
키라, 미니 마톳타 키라  
빛, 몸에 두른 빛

**星はそれぞれに水平線を飾る**  
호시와 소레조레니 스이헤이센오 카자루  
별은 저마다 수평선을 장식해

**綺羅、並び立った綺羅**  
키라, 나라비탓타 키라  
빛, 나란히 선 빛

**あめつち綾なす**  
아메츠치 아야나스  
천지를 수놓아

**きっとこのままどこにだって行ける**  
킷토 코노마마 도코니닷테 이케루  
분명 이대로 어디든 갈 수 있어

**揚々と誦む祝詞**  
요오요오토 요무 노리토  
의기양양하게 읊는 축문

**この夢は笑えるか？**  
코노 유메와 와라에루카?  
이 꿈은 비웃을 수 있을까?

**焦燥を喰らい燻っている胸の残り火**  
쇼오소오오 쿠라이 쿠스붓테이루 무네노 노코리비  
초조함을 삼키며 타다 남은 가슴속 불씨

**俺は諦めが悪いのさ**  
오레와 아키라메가 와루이노사  
나는 단념을 잘 못하는 거야

**心の外でさえうそぶく**  
코코로노 소토데사에 우소부쿠  
마음 밖에서조차 큰소리쳐

**「もっと先へ、もっと自由に、**  
「못토 사키에, 못토 지유우니,  
「더 앞으로, 더 자유롭게,

**そこに足跡はない」**  
소코니 아시아토와 나이」  
거기엔 발자국이 없어」

**綺羅、目を奪った綺羅**  
키라, 메오 우밧타 키라  
빛, 눈길을 사로잡은 빛

**洒脱な出で立ち**  
샤다츠나 이데타치  
세련된 차림새

**何よりも目映く**  
나니요리모 마바유쿠  
무엇보다도 눈부시게

**綺羅、身に纏った綺羅**  
키라, 미니 마톳타 키라  
빛, 몸에 두른 빛

**星はそれぞれに水平線を飾る**  
호시와 소레조레니 스이헤이센오 카자루  
별은 저마다 수평선을 장식해

**綺羅、並び立った綺羅**  
키라, 나라비탓타 키라  
빛, 나란히 선 빛

**あめつち綾なす**  
아메츠치 아야나스  
천지를 수놓아

**きっとこのままどこにだって行ける**  
킷토 코노마마 도코니닷테 이케루  
분명 이대로 어디든 갈 수 있어

**どこにだって行ける**  
도코니닷테 이케루  
어디든 갈 수 있어
